## r♡sie editor

발췌 문장을 예쁜 이미지 카드로 만들어주는 웹 에디터입니다. 브라우저에서 바로 작동하며, 별도 설치 없이 GitHub Pages 주소로 접속해서 사용할 수 있습니다.

---

### 시작하기

1. 사이트에 접속합니다.
2. 미리보기 화면에서 결과를 확인하며 패널에서 옵션을 조정합니다.
3. 완성되면 하단의 **현재 페이지 이미지로 저장** 또는 **현재 페이지 클립보드 복사** 버튼으로 결과물을 가져갑니다.

모바일(아이폰 등)에서는 홈 화면에 추가해서 앱처럼 사용할 수도 있습니다. Safari에서 사이트를 연 뒤 **공유 → 홈 화면에 추가**를 누르면 됩니다.

---

### 화면 구성

- **미리보기 영역**: 실제 이미지가 어떻게 나올지 보여주는 캔버스입니다. 페이지가 여러 장이면 하단 바에서 이전/다음으로 넘길 수 있고, 배율 슬라이더로 확대·축소해서 볼 수 있습니다.
- **편집 패널**: 아래 항목들을 아코디언(접었다 펼치는 방식) 형태로 모아둔 곳입니다.

---

### 편집 항목

#### 배경
- 캔버스 가로 폭과 높이(비율 선택 또는 직접 입력, 혹은 내용에 맞게 자동)를 설정합니다.
- 위아래·양옆 여백을 조절합니다.
- 배경을 단색으로 지정하거나 이미지를 첨부할 수 있습니다. 이미지는 투명도·어둡기·확대 비율을 조절할 수 있고, 캔버스 위에서 직접 드래그해 위치를 옮길 수 있습니다.

#### 제목 추가
- 첫 페이지 상단에 노출되는 제목을 입력합니다.
- 글자 크기, 본문과의 간격, 정렬, 굵기, 색상, 폰트를 각각 지정할 수 있습니다.

#### 서식 변경
- 기본 폰트(Pretendard, Noto Serif KR, 함렛, 부크크 명조/고딕)를 선택합니다.
- 줄바꿈 기준(단어/글자 단위), 가로·세로 정렬, 굵기, 글자색, 글자 크기, 첫 줄 들여쓰기, 줄간격, 문단 간격, 자간, 장평까지 세밀하게 조정할 수 있습니다.

#### 본문 편집
- 실제 텍스트를 입력하는 곳입니다. 원하는 부분을 드래그한 뒤 상단 툴바 버튼을 누르면 서식이 적용됩니다.
  - **B / I / U / S**: 굵게, 기울임, 밑줄, 취소선
  - **글자색**: 선택한 글자의 색을 바꿉니다.
  - **인용**: 선택한 문단 왼쪽에 세로 인용 바를 표시합니다 (색상 지정 가능).
  - **형광펜**: 선택 영역에 형광펜 효과를 입힙니다. 선택 없이 누르면 이미 칠해진 형광펜 색을 한 번에 전체 변경합니다. 색상 옆 스테퍼로 투명도(30~100%)를 조절할 수 있습니다.
  - **서식 지우기**: 선택 영역의 서식을 초기화합니다.
- `*` 로 감싼 텍스트와 `" "` 로 감싼 텍스트는 자동으로 지정된 색이 입혀집니다. 각각 전용 버튼으로 한 번에 제거할 수도 있습니다.

#### 스티커
- 사진을 최대 4개까지 스티커처럼 붙일 수 있습니다.
- 스타일은 **기본**(테두리만), **스티커**(테두리 + 좁은 그림자), **그림자**(경계 없이 은은하게 퍼지는 halo 그림자) 중 선택합니다.
- 테두리 두께·색상, 그림자 색상·투명도(그림자 스타일일 때만 노출)를 조절합니다.
- 캔버스에서 스티커를 클릭하면 이동·크기 조절·회전 핸들이 나타나며, 삭제 버튼(×)으로 바로 지울 수 있습니다.
- 여러 개를 겹쳤을 때는 앞으로/뒤로 버튼으로 쌓이는 순서를 바꿀 수 있습니다.

#### 출처
- 모든 페이지 하단에 고정으로 표시되는 이름/출처 텍스트입니다. 둘 중 하나만 입력해도 됩니다.
- 구분 기호(•, |), 정렬 위치, 글자색, 글자 크기를 설정할 수 있습니다.

#### 템플릿
- 지금까지의 설정(배경, 서식, 색상 등)을 이름을 붙여 저장해두고 나중에 불러올 수 있습니다.
- 기본 제공되는 **라이트**·**다크** 템플릿은 삭제할 수 없습니다.
- 저장된 템플릿은 브라우저(로컬 저장소)에 보관되며, 다른 기기나 브라우저에서는 공유되지 않습니다.

### 다크 모드

우측 상단 스위치를 눌러 라이트/다크 테마를 전환할 수 있습니다. 마지막으로 선택한 테마는 다음 방문 때도 그대로 유지됩니다.

---

### 결과물 내보내기

- **현재 페이지 클립보드 복사**: 지금 보고 있는 페이지를 이미지로 클립보드에 복사합니다. 바로 붙여넣기 할 수 있습니다.
- **현재 페이지 이미지로 저장**: 지금 보고 있는 페이지를 PNG 파일로 다운로드합니다.
- 여러 페이지로 나뉜 경우, 페이지마다 각각 저장·복사해야 합니다.

---

### 참고 사항

- 모든 작업은 브라우저 안에서만 이루어지며, 입력한 텍스트나 이미지가 외부 서버로 전송되지 않습니다.
- 템플릿 저장 등 일부 데이터는 브라우저의 로컬 저장소에 저장되므로, 브라우저 데이터를 지우면 함께 사라질 수 있습니다.
- 아이폰 사파리는 캐시가 강한 편이라, 사이트를 업데이트한 뒤에도 예전 화면이 보이면 방문 기록 및 웹사이트 데이터를 지우고 다시 접속해보세요.
